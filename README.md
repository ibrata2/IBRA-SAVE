## شنو هو؟

**IBRA SAVE** برنامج ويندوز يحمّل فيديو أو صوت من مواقع التواصل بمجرد ما تلصق الرابط. نفس فكرة موقع [cobalt.tools](https://cobalt.tools) بس كبرنامج على حاسبتك، يشتغل محلياً ويحفظ مباشرة بالمجلد اللي تختاره.

### الأوضاع الثلاثة (نفس cobalt)
| الوضع | شنو يسوي |
|---|---|
| **تلقائي** | فيديو مع الصوت بالجودة والترميز اللي تختاره |
| **صوت** | يسحب الصوت فقط: MP3 / M4A / OGG / OPUS / WAV أو الأصلي، مع صورة الغلاف |
| **بدون صوت** | الفيديو فقط بدون الصوت |

### المميزات
- **ريمكس**: يصلّح الملفات اللي ما تشتغل ويغيّر صيغتها (MP4 / MKV / MOV / WEBM) بدون إعادة ترميز وبدون فقدان جودة.
- الجودة من 144p لحد 8K، والترميز H264 أو AV1 أو VP9.
- معاينة الفيديو (العنوان، القناة، المدة، أعلى جودة) قبل التحميل.
- عدة تحميلات بنفس الوقت مع شريط تقدم وسرعة ووقت متبقي، وإلغاء وإعادة محاولة.
- لصق بضغطة، ولصق تلقائي اختياري، وسحب الرابط وإفلاته على البرنامج.
- 4 أشكال لاسم الملف، وحفظ معلومات الفيديو داخل الملف، ودعم قوائم التشغيل والترجمة.
- سجل التحميلات.
- واجهة عربي / إنكليزي، وثيم زجاج أبيض-أحمر وزجاج أسود-أحمر ووضع يتبع النظام.
- تحديث البرنامج من داخله (ينزّل وينصّب فوق النسخة القديمة)، وتحديث محرك التحميل بضغطة.

## التثبيت
نزّل `IBRA-SAVE-Setup-x.x.x.exe` من صفحة **Releases** ونصّبه. أول تشغيل ينزّل محرك التحميل تلقائياً (يحتاج إنترنت).

## للمطورين
```bash
npm install
npm start          # تشغيل
npm run dist       # بناء ملف التنصيب dist/IBRA-SAVE-Setup-*.exe
```
**إصدار نسخة جديدة:** غيّر `version` في `package.json` (مثلاً 1.0.1) وارفع التعديل على `main`.
GitHub Actions يبني الـ exe وينشره بـ Releases، والبرامج المنصّبة تتحدث تلقائياً.

### الهيكل
```
src/main.js            المحرك: yt-dlp + ffmpeg، الطابور، الريمكس، التحديث
src/preload.js         الجسر بين الواجهة والمحرك
src/renderer/          الواجهة (HTML / CSS / JS)
assets/icon.svg|png    الأيقونة
build/icon.ico         أيقونة ويندوز والمنصّب
```

## كيف يشتغل
البرنامج يحوّل خيارات cobalt (الوضع، الجودة، الترميز، صيغة الصوت، شكل الاسم) لأوامر [yt-dlp](https://github.com/yt-dlp/yt-dlp)، ويدمج ويحوّل بـ [ffmpeg](https://ffmpeg.org). مستوحى من فكرة [cobalt](https://github.com/imputnet/cobalt) المفتوحة المصدر — الكود هنا مكتوب من الصفر.
